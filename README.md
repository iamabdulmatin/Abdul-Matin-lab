# 🌌 Abdul-Matin-lab: Physics Honours Practicals 

Welcome! This is a digital archive of my **B.Sc. Physics Honours (1st Semester)** practical and computational physics codes. This repository compiles all the programming assignments developed for the Python programming lab under the **NEP (National Education Policy)** framework.

---

## 📋 Practical Index & Course Content

Here is the complete categorized list of the Python scripts included in this lab project:

### 🔢 1. Numerical Methods
*   **`BISECTION_METHOD-(AM).py`** - Finding roots of non-linear equations using the Bisection method.
*   **`NEWTON_RAPHSON_METHOD...`** - Fast root-finding implementation using the Newton-Raphson method.
*   **`ROOTS_NATURAL_VALUE-(AM).py`** - Determining the nature and calculating the roots of a quadratic equation.

### 📉 2. Curve Fitting & Graphics
*   **`FITTING(STRAIGHT_LINE)-(AM).py`** - Linear regression and straight-line fitting implementation.
*   **`FITTING(CUBIC_EQUATION)-(AM).py`** - Cubic curve fitting algorithm.
*   **`SINE&COSINE_CURVE-(AM).py`** - Plotting continuous Sine and Cosine waves using the `matplotlib` library.

### 🔄 3. Series & Iterations
*   **`FIBONACCI_SERIES-(AM).py`** - Generating Fibonacci sequence terms up to a specified limit.
*   **`EXPONENTIAL_SERIES-(AM).py`** - Evaluation and convergence check of the Exponential (\(e^x\)) series expansion.
*   **`SINE&COSINE_TSERIES-(AM).py`** - Computing Sine and Cosine values using the Taylor series expansion.
*   **`FACTORIAL-(AM).py`** & **`DOUBLE_FACTORIAL-(AM).py`** - Standard and double factorial iterative computations.

### 📊 4. Statistics & Miscellaneous
*   **`MEAN_MEDIAN_MODE-(AM).py`** - Calculating the statistical measures of central tendency (Mean, Median, and Mode) for experimental data.
*   **`PRIME_NUMBER-(AM).py`** - Prime number checking and sequence filtering algorithms.
*   **`LEAP_YEAR-(AM).py`** - Chronological logic condition for identifying leap years.
*   **`SWAP-(AM).py`** - Value swapping implementation between two variables without built-in helpers.
